## Мир интерьера — исходные материалы задания

Тема УП.11. Комплект подготовлен по структуре приложений КИМ 09.02.07-2 для учебного проектирования базы данных и приложения.

Приложение 1 — описание предметной области и права пользователей. 
Приложение 2 — пять таблиц XLSX (в CSV-копии: изображения, логотип, иконка и заглушка). 
Приложение 3 — руководство по стилю. 
Приложение 4 — четыре CSV-файла для аналитики сайта. 
Инструкция — поля, связи, порядок импорта и контрольные ситуации.

Все категории (Диваны, Столы, Кресла), модели, пользователи, цены и операции в наборе вымышлены. 
Изображения — авторские схематические иллюстрации, а не фотографии реальных товаров. 

Сначала прочитайте описание и инструкцию. XLSX и CSV содержат одинаковые данные; выбирайте один формат, чтобы не импортировать строки дважды. Остатки уже учитывают исходные заказы.

Материалы адаптированы для практики. Проверка официальной программой «Автотест» для учебной предметной области может требовать исходных названий объектов и файлов; совместимость с ней не заявляется.
