# Мир интерьера — Система автоматизации продаж

## 1. Название приложения

**Мир интерьера** — приложение для автоматизации продаж мебели и предметов интерьера.

## 2. Используемые технологии

- **Язык:** Python 3.13+
- **GUI:** PySide6 6.8+
- **СУБД:** MySQL 8.0 (вместо PostgreSQL, так как используется MySQL)
- **Драйвер БД:** mysql-connector-python

## 3. Назначение и основные функции

Приложение автоматизирует продажи товаров для интерьера. Функции:

- Каталог товаров (изображение, цена, скидка, остаток на складе);
- Авторизация по логину (гость, клиент, менеджер, администратор);
- Фильтрация по категориям (Мебель, Освещение, Декор, Текстиль);
- Сортировка по цене (возрастание/убывание);
- Поиск по названию и описанию товара;
- Скидка 25% на товары без заказов за последний месяц;
- Оформление заказа;
- Управление заказами (Менеджер, Администратор).

## 4. Порядок подготовки БД и запуска

1. Установите MySQL, создайте БД `interior_db`.
2. Выполните SQL-скрипт `db/interior_db.sql` в MySQL Workbench.
3. Установите зависимости: `pip install -r requirements.txt`.
4. Запустите: 
`python main.py`.
