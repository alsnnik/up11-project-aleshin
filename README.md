# Мир часов — исходные материалы задания

Тема 1 УП.11. Комплект подготовлен по структуре приложений КИМ 09.02.07-2 для учебного проектирования базы данных и приложения.

Приложение 1 — описание предметной области и права пользователей.
Приложение 2 — пять таблиц XLSX, их CSV-копии, изображения, логотип, иконка и заглушка.
Приложение 3 — руководство по стилю.
Приложение 4 — четыре CSV-файла для аналитики сайта.
Инструкция — поля, связи, порядок импорта и контрольные ситуации.

Все компании, модели, пользователи, цены и операции в наборе вымышлены. Изображения — авторские схематические иллюстрации, а не фотографии реальных товаров. Для модели «Радуга» изображение намеренно не задано.

Сначала прочитайте описание и инструкцию. XLSX и CSV содержат одинаковые данные; выбирайте один формат, чтобы не импортировать строки дважды. Размер обуви из исходного примера заменён вариантом исполнения часов. Учебные остатки уже учитывают исходные заказы.

В предоставленной папке КИМ приложение 4 отсутствовало. Набор аналитики разработан дополнительно по полям заданий модуля 5. Он независим от оперативных данных. Архив этого набора расположен рядом с папкой приложения 4.

Материалы адаптированы для практики. Проверка официальной программой «Автотест» для обувной предметной области может требовать исходных названий объектов и файлов; совместимость с ней не заявляется.
